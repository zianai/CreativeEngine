# Shared implementation contract (agent boundary)
All TS modules use relative imports ending .js. Root package handles deps and scripts. Node24+ built-in SQLite. No edits outside owned paths. ID strings.

contracts/index.ts exports Zod schemas and inferred types: BriefSchema/Brief, VisualPlanSchema/VisualPlan, TruthSnapshotSchema/TruthSnapshot, SourceInputSchema/SourceInput, ReviewSchema, BatchInputSchema. Also AppError(code,message,status=400,details?) and sha256 helper if useful.
Brief: project_id, workflow (four skill names), intent:string, requirements:string, product:{product_id,stage:'existing_sku'|'prototype'|'concept',truth_snapshot_id?:string}, reference_asset_ids:string[], fidelity?:'strict'|'controlled'|'exploratory', allowed_changes:string[], forbidden_changes:string[], variants:number(default3), scenes:string[](default['Studio']), aspect_ratio:'1:1'|'4:3'|'3:4'|'16:9'|'9:16', delivery_target:'internal_review'|'buyer_review'|'listing'|'marketing', provider:string(default mock), mode:'independent'|'base_variants'|'iterative', budget_usd:number(default0), claims?:{name,value}[], authorized_logo_asset_id?:string.
TruthSnapshot: id?, project_id, product_id, version:string, facts:[{name,value:string,source_asset_id,source_version,evidence_status:'verified'|'supplier_claim'|'unverified'|'concept',confirmed_at:ISO string,external_allowed:boolean}].
SourceInput: project_id, filename, data_base64, kind:'product_photo'|'cutout'|'logo'|'reference'|'document', authorized:boolean, verified:boolean, source_version:string(default1), sensitive_data_cleared:boolean. API accepts base64 raster PNG/JPEG/WebP or plain-text/PDF documents; no local user paths.
VisualPlan extends normalized Brief: id, version, strategy:'reuse'|'compose'|'edit'|'generate'|'blocked', fidelity (required), skill_version, requires_human_approval:true, reasons:string[], blocked_reasons:string[], directions:string[], created_at. Plans stored immutably.
Source records / Visual assets carry id, project_id, filename, path (internal), sha256, kind, authorized, verified, source_version, width/height/format optional, identity:'source'|'real_product'|'concept'|'mock', parent_asset_id?, task_id?, truth_snapshot_id?, review_status:'pending'|'approved'|'rejected', created_at. Core returns sanitized records plus URL /v1/assets/:id/file.
planner exports createPlan(brief:Brief, context:{assets:any[],truth?:TruthSnapshot}):VisualPlan; validatePlan(plan,context):void; loadSkills():Skill[]; compilePrompt(plan, {scene,variant,direction?,revision?}):{version:string,text:string,...}. Skills disk based.
providers/index.ts exports types ProviderRequest {taskId,attemptId,prompt,outputDir,width,height,referencePaths:string[],model?:string,signal?:AbortSignal}, ProviderResult {path,provider,model,requestId?,sessionId?,costUsd:number,mock:boolean,metadata?:Record<string,unknown>}, ImageProvider {id,capabilities():{generate:boolean,edit:boolean,exactSize:boolean,paid:boolean,maxConcurrency:number},estimateCost(req):number,healthCheck():Promise<any>,generate(req):Promise<ProviderResult>,edit(req):Promise<ProviderResult>,getResult(id):Promise<ProviderResult|null>,cancel?(id):Promise<void>}; createProviders():Map<string,ImageProvider>. ProviderError(code,message,{retryable?:boolean,uncertain?:boolean,retryAfterMs?:number}). Mock supports deterministic distinct PNG and explicit MOCK label; no placeholder fake real API outputs.
composer/index.ts exports composeImage({sourcePath,outputPath,width,height,background?,logoPath?,concept?:boolean,label?,color?,variant?:number}):Promise<void> and normalizeImage(inputPath,outputPath,width,height):Promise<void>. Strict image pixels only scaled with contain; preserve silhouette, no crop. Concept watermark deterministic. quality/index.ts exports inspectImage(path,{width,height,identity,...}):Promise<{status:'pass'|'warn'|'block',checks:any[],issues:any[],vision:any}>. Optional vision reviewer configured no silent pass.
Core public REST shape:
GET /v1/{projects,providers,skills,assets,batches,events}; lists {items:[],total:number}; POST /v1/projects {name,description?,product_id?}; POST /v1/truth-snapshots; POST /v1/assets/import SourceInput; POST /v1/briefs Brief -> brief with id; POST /v1/briefs/:id/plan -> VisualPlan; POST /v1/batches {plan_id,budget_usd,authorize_paid:false,idempotency_key?,provider?} -> batch; GET /v1/batches/:id -> batch with tasks; POST /v1/batches/:id/{cancel,resume,pause}; GET /v1/tasks/:id; POST /v1/tasks/:id/revise {instructions,allowed_changes?,budget_usd?,authorize_paid?}; POST /v1/assets/:id/review {decision:'approved'|'rejected',reviewer,notes}; POST /v1/exports {batch_id,asset_ids?} -> package with download_url; GET /v1/exports/:id[/file]. GET /v1/dashboard summary. GET /v1/assets/:id includes qa and provenance. SSE notifications with {type,entity_id,data,created_at}.
